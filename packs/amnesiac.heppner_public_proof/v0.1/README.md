# Amnesiac Heppner public proof pack v0.1

This conformance pack exercises the `amnesiac-chain` verifier profile against
real canonical producer artifacts from `thelaplage/arcs-amnesiac` commit
`1dc7660`, including the graph-snapshot export merged in PR #43.

The pack contains the initial and revised claim states from the public Heppner
proofcase, deterministic verifier reports, and the separately owned public
projection contract. A structural pass does not establish historical
authenticity or signature validity.
